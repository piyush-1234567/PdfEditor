## 📦 Libraries Used & Why

### 🚀 Express.js

**Why I chose this:**
- Needed a simple and efficient way to create a backend server  
- Provides a clean structure for handling routes and APIs  
- Built-in middleware support makes request handling easier (JSON parsing, file uploads, etc.)  
- Much faster to develop compared to using raw Node.js HTTP module  
- Large ecosystem and community support  
- Scalable for building real-world applications  

**What it is used for in this project:**
- Creating REST API endpoints  
- Handling client requests and responses  
- Managing middleware like CORS and JSON parsing  
- Serving as the core backend of the PDF Editor  

**Installation Command:**
```bash
npm install express
